### 1.4 ★ 当前有效债务结构（关键修正）

**「三件套指纹法」**：2022-03-30 那批文书的 document_id 序号呈现完美的三组配对——

```
…611004 AGMT $27,000,000  + …611005 AL&R $27,000,000  + …611006 UCC INIT
…611007 MTGE $45,250,000  + …611008 AL&R $45,250,000  + …611009 UCC INIT
…611010 MTGE $ 8,750,000  + …611011 AL&R $ 8,750,000  + …611012 UCC INIT
```

每笔贷款各配一份 AL&R 和一份 UCC-1 → **三笔彼此独立的留置，未被合并为单一
留置**（若合并，只会有一份 AL&R 且金额为合计数）。

**并贷（CEMA）的算术验证**：

```
2020-02-20  AGMT 并贷总额          $27,000,000
          − MTGE 新钱（gap）        $19,050,366
          ─────────────────────────────────────
          = 被让与的旧贷剩余本金     $7,949,634   ← 2013 年 $9,200,000 亚洲银行贷款
                                                    截至 2020-02 已摊还至此数
```

差额落在一个非整数上、而并贷总额恰为整数 $27,000,000——这是 CEMA 的典型
特征（付清旧贷余额的抵押税豁免，只对新钱 $19,050,366 缴税）。

  **至今没有任何 CO（TCO 或 Final 都没有）**。因此零成交在时间线上是
  **必然结果，不是市场需求信号**。
- **CDEC 于 2026-04-10 申报本身是「即将开卖」的强信号**：纽约实务中，

- **销售动作早在 2025 年就启动**：DOB 备案 Q01216979（2025-04-30 递交，
  2025-07-08 Approved）是**8 层 4 套样板房（8A / 8C / 8F / 8K）的临时使用许可**
